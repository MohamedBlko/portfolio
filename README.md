# Mohamed Marou Belko - Electrical Engineering Portfolio

This repository contains a static electrical engineering portfolio built for
GitHub Pages.

## Sections

- Recruiter-focused hero
- About
- Technical skills by engineering domain
- Engineering projects as mini case studies
- Engineering process
- Timeline
- Certifications and readiness
- Engineering gallery
- Reports and publications
- Contact and resume PDF

## How to customize

Edit `index.html` to update the CV content, project cards, links, and contact
information. For each project, include:

- objective
- responsibilities
- software
- measurable result
- gallery assets
- report, drawing, simulation, or demo link

The visual theme is driven by `styles.css` and `script.js`: dark electrical
engineering colors, steel accents, orange highlights, a Three.js 3D homepage
power hub, interactive project modals, and animated project simulations. The
resume PDF is stored in `assets/`.

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

After pushing to GitHub:

1. Go to the repository settings.
2. Open **Pages**.
3. Set the source to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Save.

GitHub will publish the portfolio automatically.
