# Microcontroller data acquisition

Embedded interfaces | Sampling | Peripheral configuration

## Objective
Understand how hardware timers and DMA coordinate sampled input and output with a microcontroller application.

## Engineering work
- Organize C and assembly routines around peripheral data.
- Configure timer-triggered acquisition and output.
- Examine DMA transfer settings and interrupt boundaries.
- Keep supplied starter material distinct from application changes.

## Outcome
Source projects and laboratory archives are present, including C, assembly, IOC and Keil files. The gallery uses configuration references from the lab handout to explain the context of the archived work.

## Limits
The handout images are not claimed as personal test results. Firmware has not been rebuilt, and the archive contains both starter code and modified project variants.

## Evidence
ELE3312 laboratory 8 handout and archived STM32 source projects.
