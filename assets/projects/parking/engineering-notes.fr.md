# Détection des places de stationnement

ELE1001, projet d'équipe, 2019.

## Objectif
Représenter l'occupation de quatre étages de quatre places. Indiquer le nombre
de places libres et les coordonnées de la prochaine place disponible.
Les niveaux sont A, B, C et D; les places vont de 1 à 4. Par exemple, B3 désigne
le niveau B, place 3. Le modèle du site utilise cette même notation A1-D4.

## Réalisation
Le rapport décrit les capteurs, le balayage, l'horloge, les compteurs, les
registres, le multiplexage et les portes logiques. Les sorties utilisent des
afficheurs à sept segments. L'archive comprend les photographies des circuits
d'essai et soudé, les schémas et les vidéos de laboratoire.

## Éléments publics
Photographie de la plaque d'essai, schéma logique annoté, circuit soudé et vidéos
sans son montrant les états d'affichage.

Le modèle interactif classe les entrées par étage puis par place. Il illustre la
priorité, sans reproduire les délais de propagation, le câblage ni tous les modes
de défaillance du matériel.

## Portée
Projet universitaire en équipe, pas une installation de stationnement déployée.
Aucun pourcentage de fiabilité ni gain de performance terrain n'est revendiqué.
Les identifiants personnels du rapport sont omis.
