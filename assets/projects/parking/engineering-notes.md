# Parking lot place finder

ELE1001, team project, 2019.

## Objective

Represent occupancy in a model with four levels and four spaces per level.
Report available spaces and the coordinates of the nearest available bay.
Levels are labeled A, B, C and D; spaces are numbered 1 to 4. For example,
B3 means level B, space 3. The browser model uses the same A1-D4 notation.

## Implementation

The project report describes sensor states, a scanning circuit, a clock,
counters, registers, multiplexing and logic-gate processing. Seven-segment
displays represent the output. The archive contains breadboard and soldered
board photographs, circuit diagrams and lab videos.

## Evidence on the portfolio

The browser priority model orders inputs by level and then bay. It is an
illustration, not a reproduction of propagation delays, wiring or all failure
modes of the physical circuit.

## Scope

This was an academic team project, not a deployed parking installation.
No reliability percentage or field-performance improvement is asserted.
The public summary omits the personal identifiers in the original report.
