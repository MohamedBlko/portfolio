Engineering process

Engineering approach

A structured approach to academic projects, prototypes and technical deliverables.

  1. 01Problem

    Define operating context, constraints, loads, risks and acceptance criteria.

  2. 02Analysis

    Run calculations, review standards, compare architectures and document assumptions.

  3. 03Simulation

    Validate behavior in MATLAB/Simulink, LTspice, PLC logic or system models.

  4. 04Design

    Create schematics, I/O lists, cable schedules, test plans and technical notes.

  5. 05Testing

    Verify sequence behavior, protection logic, measurements and failure cases.

  6. 06Documentation

    Record results, limitations, procedures and traceability for the next technical user.
